# 浅色主题（Day）

Night 仍是默认主题，写在 `:root` 上，已有页面不用做任何改动。Day 是新增的浅色主题：在 `<html>` 上加 `data-theme="day"` 就能切换。组件、尺寸、字体、间距和动效全部沿用 Night，只换颜色。

```html
<html lang="zh-CN" data-theme="day">
```

## 什么时候用
- 用 Day：开发工具、表单和表格密集的工作台、需要长时间阅读的文档、要打印或投影的页面。
- 继续用 Night：数据叙事、学习指南这类沉浸式页面，以及已经交付的两份页面。
- 一个页面只用一个主题，不在同一屏里混排两种底色。如果页面同时提供两套主题，初始值按 `prefers-color-scheme` 选，再给一个带 `aria-pressed` 的切换按钮；切换只改 `data-theme`，不改任何组件的类名。

## 从 Night 推到 Day 的规则
- 层级的含义不变：`void` 仍是页面底，`panel` 仍是卡片、图表、表格的面，`panel-2` 仍是表头、图注等二级面。Day 里卡片（白）比页面底（#f4f6f9）亮，靠 1px `rule` 描边分层，依然不用投影。
- 文字四级的层次不变：`ink`、`ink-2`、`dim`、`faint` 在三种底色上都 ≥4.5:1。
- 强调色仍然只有琥珀和冰蓝，但换成深色版本，可以直接作文字：`amber` #995300，`ice` #0a5fae。琥珀实底上的文字改为白色（`on-amber` 指向 `panel`）。
- 数据色 `l0`–`l7` 保持色相和顺序，压暗到能直接作 12px 文字，包括 12% 淡底的胶囊。同一个对象在两个主题里用同一个序号。
- 热力格改成浅底深字，冷（蓝）到热（红）的顺序不变，每级 ≥7.1:1。
- 代码块跟随浅色：`code-bg` #f2f5f9、`code-bar` #e8ecf2，语法色仍取 `l1`、`l2` 和 `amber`。
- 图表连线标签仍是不透明芯片：`chart-label-bg` 为白色，文字用 `chart-text`。

## 组件在 Day 里的变化
组件结构和尺寸不变。原来写死了深色值的几处，由 `bundle.css` 末尾的 Day 覆盖层换成 token，只在 `[data-theme="day"]` 内生效：
- 统计数字、数据条数字、周期表代号：白字改为 `ink`。
- 统计卡、回到顶部、规格条、左侧目录、条形图轨道、周期表格子：深色底改为 `panel` / `panel-2` / `void`。
- 章节空心编号的描边、表格行线、代码块描边、复制按钮描边、事实校准卡的删除线：改用 Day 的 `amber`、`rule`、`rule-2`、`bad`。
- 资源按钮 `.btn`：底色改为 `ink` 3%，悬停底色用 Day 的 `ice` 8%（原来写死了 Night 的白色 3% 和冰蓝 8%）。
- 悬停：导航和目录的悬停底改为 `ink` 5%；热力格悬停略微压暗（brightness .96），不再提亮。
- ModuleCard 顶条的发光减弱为数据色 45%；背景网格和点阵改用 Day 的 `ice` 着色，不透明度仍不超过 0.11。
- 操作按钮 `.act` 和 4 个 Agent 组件只用 token 写成，Day 下不需要覆盖；`pulse` 脚冲光晕取当前主题的 `amber`。
- 状态胶囊和 Banner 的 12% 淡底放在 `void` 或 `panel` 上：Day 的 `warn`（`l4`）放在 `panel-2` 上只有 4.49:1。

写新组件时：颜色一律取 token，不写死 `#fff` 或深色 `rgba()`；需要透明度时写 `color-mix(in srgb, var(--token) N%, transparent)`，这样换主题时不用改组件。

## 例外
- 主标题强调词：Day 里不用 `amber` → #ffd9a0 的渐变（浅色端在浅底上看不清），直接用 `amber` 实色。
- 发光：只保留在里程碑和当前项上，Day 用 `shadow-glow` 的 Day 值（更淡）。
- GitHub README 不受影响：原则 10 本来就要求在 GitHub 的浅色和深色主题下都能读。

## 验收
- 用 Day 的页面，在 Day 下跑完验收清单第 1–6 组，对比度按 Day 的色值计算。
- 同时提供两套主题的页面：切换 `data-theme` 前后，元素尺寸、布局和截断结果必须完全一致，只有颜色变化。
