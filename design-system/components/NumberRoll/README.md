数字滚动：会更新的读数（进度、用量、计数）变化时，只有变化的数位纵向滚到新值，没变的数位不动。读屏读一份隐藏的真实数值。

## 用法
- 写成 `<span class="roll">1,284,560</span>`：初始内容就是真实数值，没有脚本也可读。脚本把它拆成两部分：`.sr-only` 里放完整数值给读屏，`aria-hidden` 的一行里每个数位是一列 0–9（`.roll-d`），用 `--d` 选中当前数字。
- 更新时调用 `setRoll(el, "1,291,874")`：数位列原地改 `--d`，`transform` 过渡 `dur` / `ease`；逗号、小数点、百分号等非数字字符直接替换。位数变化时从左边补位或去位，新补的数位直接显示，不滚动。
- 数位宽度靠 tabular-nums 等宽；外层字号、字体、颜色照所在组件（StatTile 的 `b`、TaskRow 的进度胶囊）。
- 用在数值真的发生了变化的地方：Agent 运行中的用量、任务进度、筛选后的计数。
- 减弱动效：数位直接跳到新值。

## 不要
- 不要做从 0 数起的入场：页面打开时直接显示真实数值。数到一半时屏幕上的数是错的，截图和读屏都会拿到错的数。
- 不要用在静态数字上（StatTile 的标题数字、表格里的数据）：数字不变就不需要动。
- 不要在数值高频变化（每秒多次）的地方用：数位还没停稳就又变了，改成直接替换文字。
