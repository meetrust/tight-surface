筛选重排：筛选、排序或增删以后，网格里的元素按“退出 → 移动 → 进入”编排，留下的元素从旧位置移到新位置，新元素从触发操作的按钮开始依次进入。动效规则 2–4 的参考实现。

## 用法
- 结构：`.reflow` > `.reflow-bar`（筛选按钮 `.fbtn` + 计数 `.reflow-sum`）+ `<ul class="reflow-grid">`。计数写成“显示 3 / 8 个工具”，放在 `role="status"` 里，读屏会播报筛选结果。
- 筛选按钮是单选：按下的一个 `aria-pressed="true"`，其余为 `false`；再按已按下的按钮不做任何事。
- 三段各用一个 `dur`：离开的元素淡出（`opacity` 1 → 0）；留下的元素用 FLIP 移到新位置；新元素从 `enter-opacity` 上移 `enter-shift` 进入。没有位移时跳过移动段。
- 错峰：新元素按与触发按钮的距离排序，间隔 `stagger`，总延迟不超过 `stagger-max`，超过时压缩间隔。
- 打断：上一轮还没播完又换了筛选时，先取消正在播的动画，再从当前布局开始新一轮。
- 减弱动效：直接切换到最终结果，不播放任何一段。
- 用 `el.animate()` 实现，所有参数从 CSS 读取，见预览里的脚本。排序同样适用：先换顺序，再用 FLIP 补位移。

## 不要
- 不要让留下的元素瞬移到新位置。
- 不要让离开和进入同时播放：两组元素会在同一个格子里叠在一起。
- 不要给网格里的元素加缩放或旋转；位移和不透明度就够了。
