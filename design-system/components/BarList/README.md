原生条形图：名称 / 轨道 / 数值三列，比图表库更清晰、更好控制。

## 用法
- 每行 `style="--c: var(--lN); --v: <0–100>"`，条形宽度 = `--v`%，从 55% 透明到实色的同色渐变。入场 `grow`：从 `grow-from` 横向展开，一个 `dur`；每行写 `--i`（0、1、2…）时按 `stagger` 从第一行开始依次展开。
- 名称列 140px（≤760px 为 118px，必须放得下最长名称，不许截断）；数值列右对齐、tabular-nums、带单位。
- 轨道背景每 25% 一条刻度线，下方 `.bars-axis` 写刻度。
- 按数值降序排列；图注写“合计”，合计必须与首屏统计一致。
