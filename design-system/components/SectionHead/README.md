章节标题：两位编号 + 大写 eyebrow + h2，手册版式与地图版式各一种写法。

## 用法
- 手册版式用 `.sec-head`：`.sec-no` 是 88px 的空心琥珀描边数字，右侧放 `.eyebrow`（英文、大写、`amber`）、h2（`fs-2xl`，900）和可选的 `.sub`（`dim`，`fs-base`）。
- 地图版式用 `.sh`：左侧 `.sh-idx`（14px 琥珀实心编号），中间 eyebrow + h2，右侧 `.sh-meta`（faint，大写），底部 1px `rule` 分隔线。
- 编号从 00 或 01 连续递增；页尾的“来源 / 说明”也要编号（如 07），不要用 ↗ 之类的字符代替。
- ≤760px 时两种都变成单列，`.sh-meta` 隐藏。

## 提供
编号、英文 eyebrow、中文标题；副标题可选。

## 不要
- 不要在一个页面里混用两种写法。
- eyebrow 不写中文；h2 不加图标。
