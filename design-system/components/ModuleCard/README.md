模块卡：一个对象（仓库、课程、模块）一张卡，顶部 3px 数据色发光条，左侧大序号。

## 用法
- `style="--c: var(--lN)"` 决定整张卡的识别色：顶条、序号、层级标签、头部 10% 斜向淡底、悬停描边与着色投影。
- 头部：`.mod-idx`（46px 序号）+ `.mod-layer`（“L1 · 数学”，大写字距）+ 等宽 h3（`t-code-title`）+ 一句话定位（`ink-2`）+ `.specs` 规格条。
- 主体按 MECHANISM / HIGHLIGHTS / OUTPUT 分块，每块以 `.k-chip` + 中文小标题开头。
- ≤760px：头部单列，序号 34px，标题 22px。

## 不要
- 一张卡只用一个数据色；不要在卡内再混入其他系列色（引用其他模块时用 `.rel` 胶囊）。
