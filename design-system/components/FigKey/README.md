HTML 图例：色块 + 名称 + 数值。图表库自带的图例一律隐藏，换成它。

## 用法
- `.fig-key`：每项 `style="--c: var(--lN)"`，12px 圆角方块 + 名称（`ink-2`，nowrap + 省略号）+ 右侧数值（`t-stat` 字体，tabular-nums）。容器宽度够时自动排成两列，否则一列。
- `.fig-key.compact`：只有名称的系列图例，固定 2×2，避免 3+1 的不平衡换行。
- `.keys`：线型图例（实线 / 虚线），说明连线含义。
- 颜色与图中同一系列完全一致，顺序与图中绘制顺序一致。

## 为什么
图表 SVG 在窄屏会整体缩小，自带图例会跟着缩到 6–8px；HTML 图例始终是 13px。
