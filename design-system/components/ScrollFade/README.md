滚动边缘渐隐：横向滚动的表格和代码块，在还有内容的一侧显示 24px 渐隐，滚到头就消失，提示“这里还能滚”。

## 用法
- 在滚动容器外面包一层 `<div class="scroll-fade">`，滚动容器是它的第一个子元素（`.tbl`，或代码块里的 `pre`）。滚动容器照常带 `tabindex="0"`、`role="region"` 和全页唯一的 `aria-label`。
- 脚本按滚动位置在外层写 `data-more`：左边还有内容写 `start`，右边还有写 `end`，两边都有就都写；滚动和尺寸变化时更新。渐隐的出现和消失过渡 `dur`。
- 渐隐的颜色要与滚动容器的底色一致：表格用默认的 `panel`；代码块写 `style="--fade-bg: var(--code-bg); --fade-r: 0"`（代码块的圆角在外层 `.term` 上）。右侧渐隐的圆角 `--fade-r` 默认 15px，与 `.tbl` 的内圆角对齐。
- 固定首列的表格（`.tbl.sticky-first`）：左侧渐隐从首列的右边缘开始，脚本读取首列宽度写进 `--fade-start`，不盖住首列。
- 只用颜色渐隐，不用 `backdrop-filter` 模糊：模糊代价高，还会让文字发虚。
- Windows 对比度主题下渐隐去掉。

## 不要
- 不要用渐隐代替键盘可滚动：容器的 `tabindex` 和 `aria-label` 照样要写。
- 不要给不会横向滚动的容器加：没有可滚动的内容时，`data-more` 为空，渐隐不出现，但也没有必要包这一层。
