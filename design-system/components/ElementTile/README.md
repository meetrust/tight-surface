周期表格子：用于“总览”型页面，一格一个对象，等高网格排布。

## 用法
- 网格行高固定（桌面 124px，≤760px 112px），格子之间 12px；整格是一个链接，跳到对应档案。
- 自上而下：`.el-head`（两位序号 + 单位，如“20 讲”，12px）/ `.el-code` 等宽代号（20px，700，Night 白色、Day `ink`）/ `.el-name` 中文名（12px，`ink-2`，nowrap + 省略号）/ `.el-av` 资源图标（13px）。
- 资源图标：有资源 `.on`（amber），没有则灰色（Night #4a5670，Day 为 `faint` 50%）；每个图标都带 `title` 和 `.sr-only` 文字，不靠颜色单独表达。
- 底色是数据色 16%（Day 为 10%）→ `panel` 的斜向渐变，描边数据色 45%；悬停上浮 3px 并加着色投影。
