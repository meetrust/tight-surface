图表外框：带编号的 figcaption、图表主体、可选的图脚。页面里每一张图都放在 Figure 里。

## 用法
- figcaption 左侧 `<b>FIG.0n · 标题</b>`（`t-fig-label`，ink），右侧一句读图提示（`dim`，`fs-xs`）。
- 编号全页连续：FIG.01、FIG.02……交付前检查顺序。
- `.fig-body` 内边距 `sp-5`（≤760px 为 `sp-4`），内容超宽时只在这里横向滚动，页面本身不许横向溢出。
- `.fig-foot` 放线型图例（`.ln` 实线 / `.ln.dash` 虚线）、补充说明，文字 `faint`、`fs-2xs`。
- 里程碑等符号用 `.ms-key` 这类 CSS 形状，和图里的标记同形同色，不用 ◆ 等字符。

## 提供
编号、标题、读图提示、图表内容。

## 不要
- 不要省略编号或让编号跳号。
- 图表文字（Mermaid 或 SVG）渲染后不得小于 12px，见“数据可视化”一节。
