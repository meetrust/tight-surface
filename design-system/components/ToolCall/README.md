工具调用胶囊：一行摘要加一组 26px 等宽胶囊，每个胶囊是一次工具调用，点开看参数和结果。

## 用法
- 摘要 `.tools-sum`：“4 次工具调用 · 2 条消息”，数字用 `<b>`（Display 字体）。
- 胶囊 `.tool` 是 `<button>`：状态环 + 工具名 `.nm`（取 `--c` 数据色）+ 参数 `.arg`（“→ 文件名”，过长省略）+ 用时 `.ms`。`--c` 按工具种类固定分配（读文件 `l1`、执行代码 `l6`、搜索 `l2`、写文件 `l4`）。
- 状态图标用 StatusRing（12px）：成功 `data-state="done"`（`good`），失败 `failed`（`bad`），进行中 `running`（`amber`，不知道进度时匀速旋转），胶囊同时写 `data-state="running"`，描边变虚线。状态变化时只改环的 `data-state`，对勾或叉会画出来。每个状态都在按钮里带一个 `.sr-only` 文字（“成功：”“失败：”“进行中：”），颜色不单独表达状态。
- 用时：进行中的调用实时计时，每个 `tick`（100ms）刷新一次 `.ms`，减弱动效、全页暂停或页面在后台时每秒一次；结束时定格为最终用时。写法见预览里的脚本。
- 展开：按钮写 `aria-expanded` 和 `aria-controls`，对应的 `.tool-detail` 里放 CodeBlock（`.term`）；收起时给 `.tool-detail` 加 `hidden`。展开中的胶囊是 12% 淡底加实色描边。
- 用时之和、调用次数与摘要一致。

## 不要
- 不要用颜色区分成功和失败以外的东西；工具种类色只表示种类。
- 不要把参数原文塞进胶囊；超过一行的内容放进展开区。
- 不要用 ✓ ✕ 等字符；状态图标只用 StatusRing，其他图标只用 Lucide（见 Icon）。
