首屏关键数字：卡片式 `.stat`（手册版式）和通栏式 `.datastrip`（地图版式）。

## 用法
- 数字用 `t-stat`（Chakra Petch 700，Night 白色、Day `ink`，tabular-nums），下面一行 `fs-xs` `dim` 说明，说明写清单位和口径（“标准路线 · 17 周”）。
- 每个数字都必须能在正文里找到来源或推导（例如 Star 合计 = 各仓库之和）；交付前逐个核对。
- 范围用 en dash：`$75–175`、`8–12 h`；约数用“≈”。
- 一组 3–5 个；`.datastrip` ≤760px 时每行 3 个。

## 不要
- 不放没有出处的装饰性数字。
