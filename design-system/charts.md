# 图表实现：原生优先

网页里的图表一律用原生 HTML / CSS 实现，内联 SVG 只用来画线条和形状。默认不引入 Mermaid、Chart.js、ECharts 这类图表库。

## 为什么
Mermaid 用自己的布局引擎和样式表，生成一整张按 viewBox 缩放的 SVG：内部样式用带 ID 的选择器和 `!important` 内联样式，文字放在 `foreignObject` 里。设计系统的 token、字号下限、断点和交互规则只能从外面去覆盖它，每种图都要单独打补丁。已交付的两个页面里，图表相关的问题几乎都出在这里：
- 窄屏时整张图跟着缩小：雷达图文字只剩 5.6–6.9px，饼图图例约 7px，象限图约 7.8px。
- 自带的图例和点标签无法控制位置，象限图的标签互相压住。
- 连线标签底色默认半透明（0.5），文字看不清。
- 外层 SVG 分组和内层 HTML 用的是同一个类名，聚焦时本该高亮的标签也一起变灰。
- `foreignObject` 在 Safari / iOS 上会闪现一团重叠的文字。
- 默认主题偏浅，和暗夜风格对不上（旧版 FIG.07）。
- 配置随版本变化，要逐项试错：frontmatter 里带连字符的值会被丢掉，themeCSS 写法会弄坏样式，甘特图的 ID 带前缀，分区默认透明度只有 0.2。

用原生方式实现的图（依赖图谱 FIG.01、条形榜 FIG.05、成本曲线 FIG.06、甘特路线 FIG.09、课程周期表、新版象限图 FIG.07）直接使用 token 和组件样式，没有出现这类问题。

## 适用范围
- **网页、Artifact、Dashboard 里的图表**：原生实现。
- **Markdown 手册**（`docs/` 下的 `.md`）：可以用 Mermaid，因为 GitHub 和多数编辑器会直接渲染它。配色仍取本系统的 token。
- **README.md**：不用 Mermaid，关系和流程写成表格或列表，见“GitHub README”。
- **例外**：节点超过约 15 个、连线复杂、必须自动布局的有向图。优先用布局库（如 dagre、ELK）只计算坐标，节点和标签仍然用 HTML 渲染。如果确实要把整张图交给 Mermaid，在页面注释或 README 里写明原因，并遵守“数据可视化”和“交互状态”两节里关于 Mermaid 的全部规则。

## 结构规则
- 需要阅读的文字（标题、刻度、标签、图例、数值）一律放在 HTML 里，使用页面字体和 token。不要用 SVG `<text>` 承载这些文字，更不能让整张图按 viewBox 缩放。
- SVG 只画线、面和形状：连线、曲线、坐标轴、扇区。描边加 `vector-effect: non-scaling-stroke`。
- 坐标用百分比，或者从容器实际测量得到。点位写在元素上，例如 `style="--x: .46; --y: .78"`，CSS 里用 `left: calc(var(--x) * 100%)` 定位。
- 数据写在标记里：每个数据项对应一个元素，或者放一段 `<script type="application/json">`。即使 JS 没有运行，也能以列表或表格读到全部数据。
- 容器尺寸变化时，用 `ResizeObserver` 重新计算连线和标签位置，不要整体缩放。窄屏时改变布局（例如图和图例上下排列），而不是把图缩小。
- 图表外框用 Figure，图例用 FigKey，热力用 `heat-1`–`heat-5`，系列色用 `l0`–`l7`，标签芯片和胶囊的高度遵循尺寸规范。

## 常见图形的做法
| 图形 | 原生做法 | 参考 |
|---|---|---|
| 条形 / 排行 | CSS grid 三列（名称 / 轨道 / 数值），条宽 = `--v`% | BarList、FIG.05 |
| 饼图 / 环图 | `conic-gradient`，或 SVG 圆环配合 `stroke-dasharray`；名称、数值、百分比放在 HTML 图例里 | FigKey |
| 折线 / 面积 | SVG `path`（`preserveAspectRatio="none"` + 非缩放描边），坐标轴、刻度和数据标签放 HTML | FIG.06 |
| 散点 / 象限 | 用 `--x` / `--y` 百分比绝对定位的点，标签依次尝试上、右、左、下避让 | FIG.07 |
| 雷达 | JS 按数据算出多边形顶点，画 SVG `polygon`；轴名用 HTML 绝对定位在外圈 | 推荐做法，两份页面里还没有现成实现 |
| 甘特 / 时间线 | CSS grid，列数 = 时间单位，条形用 `grid-column: 起点 / span 跨度` | FIG.09 |
| 有向图 / 依赖图 | 节点用 CSS grid（`grid-template-areas`）排版；JS 测量节点位置后画 SVG 连线；连线标签是 HTML 芯片 | FIG.01 |
| 热力表 | 表格加 `heat-N` 底色 | DataTable |
| 卡片矩阵 / 周期表 | CSS grid，固定行高 | ElementTile |

## 质量要求
- 每个宽度下，图内文字都不小于 12px，标签零重叠，页面不横向溢出。
- 交互遵守“交互状态”：悬停只响应鼠标，键盘聚焦只在 `:focus-visible` 时高亮，轻点后不残留状态。
- 图表本身不依赖第三方 CDN，CDN 故障或离线时也能完整显示（字体例外，会退回系统字体）。
- 每张图都有文字等价物（图例、列表或表格），图形容器带 `role` 和 `aria-label`。
