# 动效

动效只用来说明变化：元素从哪里来、到哪里去，数值和状态变成了什么。这一节展开原则 11：参数、八条规则、九个标准模式、不采用的动效和实现方式。规则来自《大模型 Attention 架构与技术路线对照》三张动态图的实现，以及对 Motion、GSAP、Anime.js、Three.js 和 React Bits 的比较；只借思路，代码全部按本系统的 token 自写。

## 参数

| token | 值 | 用途 |
|---|---|---|
| `ease` | cubic-bezier(.2, .7, .2, 1) | 所有过渡、移动和入场；匀速的循环（状态环旋转、连线流动）用 linear |
| `dur` | .28s | 状态过渡，以及编排里的每一段：退出、移动、进入、连线 |
| `dur-drawer` | .35s | 抽屉 |
| `dur-loop` | 1.6s | 表示“进行中”的循环的一个周期：脉冲点、状态环旋转、连线流动 |
| `lift` | translateY(-2px) | 悬停抬升 |
| `enter-shift` | 14px | 入场位移：上移淡入 `rise` 的距离，分步切换的横向位移 |
| `enter-opacity` | .25 | 入场的起始不透明度 |
| `grow-from` | .12 | 条形入场展开的起始比例 |
| `stagger` | 24ms | 错峰间隔 |
| `stagger-max` | 240ms | 一组错峰的总延迟上限 |
| `tick` | 100ms | 实时计时的刷新间隔 |

脚本从 CSS 读取这些值，不写死数字：

```js
const css = getComputedStyle(document.documentElement);
const ms = (name) => { const v = css.getPropertyValue(name).trim(); return v.endsWith("ms") ? parseFloat(v) : parseFloat(v) * 1000; };
const DUR = ms("--dur"), STAGGER = ms("--stagger"), STAGGER_MAX = ms("--stagger-max");
const EASE = css.getPropertyValue("--ease").trim();   // 可以直接传给 el.animate()
```

## 规则

1. **只说明变化。** 允许的动效只有五类：入场、位置变化、数值变化、状态变化、表示“进行中”的循环；悬停反馈按原则 4。不为装饰加动效，见“不采用”。
2. **编排顺序：退出 → 移动 → 进入 → 连线。** 一次变化里，离开的元素先淡出，留下的元素再移到新位置，新元素随后进入，连线等两端都到位后再画出；每一段一个 `dur`。原位替换（分步、标签页的面板）只播放进入，不等退出。
3. **布局连续。** 筛选、排序、增删和切换时，留下的元素从旧位置移到新位置，不瞬移。做法（FLIP）：先记下旧位置，换好布局，再用反向位移把元素放回旧位置，然后过渡到零。
4. **错峰从焦点开始。** 一组元素依次进入时，从焦点（当前项、查询位置、触发操作的控件）开始，按距离向外展开，间隔 `stagger`；总延迟超过 `stagger-max` 时按比例压缩间隔。
5. **默认可读。** 页面的初始状态就是最终状态：动画只写起点（`from` 关键帧或反向位移），不先把内容藏起来等脚本显示。入场从 `enter-opacity` 开始，不从 0 开始；编排里还没轮到的元素可以暂时不显示，编排结束时全部可见。不在视口里的图直接显示最终状态，回到视口时不补播。数字不做从 0 数起的入场：数到一半时屏幕上的数是错的。
6. **可以暂停。** 自动开始、持续超过 5 秒的动效（流动的连线、循环播放的演示）必须有暂停按钮，一个按钮管全页（WCAG 2.2.2），见 PauseMotion；页面切到后台时，脚本驱动的循环也要停。暂停只停循环，不停入场：暂停时新出现的内容照常进入。表示“进行中”的状态指示（脉冲点、状态环）随任务结束而停止，不另设按钮，但同样受全页暂停控制；实时计时在暂停时改为每秒刷新一次。
7. **参数取自 token。** 时长、缓动、位移、错峰都取上表的 token；脚本里也一样。Kumo 组件自带的动效按“Kumo 适配”一节处理。
8. **减弱动效。** `prefers-reduced-motion: reduce` 时关闭全部动画、过渡和平滑滚动，直接显示最终状态；实时计时改为每秒刷新一次；暂停按钮隐藏（已经没有会动的东西）。脚本在开始动画前检查这个设置，并监听它的变化。

## 标准模式

| 模式 | 组件 | 用在哪里 | 怎么动 |
|---|---|---|---|
| 筛选重排 | Reflow | 筛选、排序后的卡片和胶囊网格 | 按规则 2–4：退出、移动、从触发的控件开始错峰进入 |
| 全页暂停 | PauseMotion | 有持续动效的页面 | 一个按钮暂停全页的循环动画和脚本循环，入场照常 |
| 数字滚动 | NumberRoll | 会更新的读数：进度、用量、计数 | 变化的数位纵向滚到新值，没变的数位不动 |
| 状态环 | StatusRing | TaskRow、ToolCall 的状态 | 排队的虚线环 → 进度弧 → 完成画出对勾，失败画出叉 |
| 实时计时 | ThinkingTrace、ToolCall | 运行中的耗时 | 每个 `tick` 刷新一次，结束时定格 |
| 滑动选中块 | SlideTabs；Kumo Tabs | 单选的标签、分段控件 | 选中底块从旧位置滑到新位置 |
| 分步方向过渡 | StepFlow | 多步确认、向导 | 前进时新内容从右侧进入，后退时从左侧进入 |
| 滚动边缘渐隐 | ScrollFade | 横向滚动的表格和代码块 | 还有内容的一侧显示 24px 渐隐，滚到头消失 |
| 提示分组 | Kumo Tooltip + TooltipProvider | 工具栏里只有图标的按钮 | 第一个提示等 600ms 出现，400ms 内移到相邻按钮立即出现 |

## 不采用

- 装饰背景：动态渐变、粒子、WebGL 背景。每页只有一种静态纹理（原则 3）。
- 文字特效：拆字逐个出现、乱码解码、打字机、翻牌、流光、模糊入场、故障抖动。文字一出现就是最终内容。
- 跟随指针的效果：光标拖尾、指针聚光、磁吸按钮、3D 倾斜卡片。悬停反馈只有原则 4 的位移和描边。
- 跑马灯、无限滚动的标志墙；跟着滚动进度走的视差、缩放和接管滚动。
- 弹簧和回弹作为默认缓动。只有拖动松手这类跟随手势的场景可以用，并写明原因。
- 从 0 数起的数字入场（规则 5）。
- 长按确认、滑动确认：对行动不便的用户不友好，拖动操作还必须有单击替代（WCAG 2.5.7）。危险操作用写明后果的 `.act.danger`。
- 失败时抖动、完成时撒花。

## 实现

- 先 CSS，再 Web Animations API（`el.animate()`），最后才是动画库；能用 CSS 过渡写的不写脚本。
- React 项目可以用 Motion（`motion`，MIT），参数同样取自 token。不用 GSAP：它免费但不是开源许可（Webflow 的 Standard “No Charge” 许可，Webflow 可以修改条款，违反条款时可以终止许可），而本系统的代码以 MIT 发布。
- 不复制组件库的动效代码。React Bits 的许可是 MIT 加 Commons Clause，不允许把组件以移植形式再分发；本系统只借交互思路。
- 尽量只动画 `transform`、`opacity` 和 SVG 的描边虚线；绝对定位的小部件（选中底块、进度条填充）可以过渡宽度。
- 打断：新的变化开始时，先结束或取消正在进行的动画，再从当前布局开始新一轮，不叠加。
- 循环动画要让全页暂停停得住：页面自己写的 CSS 循环加 `data-loop`；脚本驱动的循环监听 `ts:motion` 事件，或在每一帧读取 `html[data-motion="paused"]`，同时在 `document.hidden` 时停下。

## 验收

- `tools/page_check.py` 的四项动效检查：
  - `motion-reduce`：减弱动效下，加载后没有还在播放的动画、过渡（含 `el.animate()`），也没有平滑滚动。
  - `motion-readable`：没有减弱动效偏好时，加载并等入场编排结束（1.5 秒）后，没有不透明度（连同祖先）低于 0.2 的文字；`aria-hidden` 里的装饰文字除外。
  - `motion-pause`：无限循环的动画有全页暂停按钮（`[data-motion-pause]`，或名字含“暂停”的按钮），按下后循环全部停住；脚本持续改动 SVG 或 HTML 属性的（`requestAnimationFrame`、计时器），按下后也要停。状态指示（`.trace-dot`、`.ring-arc`、带 `data-motion-status` 的元素）不要求单独的按钮，但按下后同样要停。没有按钮、脚本却一直在改画面时报 WARN，人工确认。
  - `motion-token`（WARN）：过渡和动画的时长不是 `dur` / `dur-drawer` / `dur-loop`，或缓动不是 `ease`（循环可以用 linear）；CSS 和 `el.animate()` 都查。最常见的原因是 `transition` 里漏写了缓动，浏览器会用默认的 ease。
- 组件预览由 `tools/check_components.py` 跑同样的四项，都按 FAIL 计。Kumo 对照页（`kumo/demo/`）也跑 `page_check.py`，基线 0 FAIL、0 WARN。
- 画在画布上的循环（canvas、WebGL）脚本检查看不到，要人工确认：暂停按钮能停住它，切到后台也会停。
- 人工按正常速度把每个过渡看一遍：先后顺序符合规则 2，没有瞬移，没有一闪而过的空白。
